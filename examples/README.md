# Examples

Worked examples built on the same shape as the QA pipeline in this repository: an event in, a safety screen, an agent
with the fewest tools it needs answering in a schema, deterministic checks, and a person at the end.

| Folder | What it is |
|---|---|
| [company-agents/](company-agents/) | A baseline set of agents and workflows for running a company's everyday engineering traffic through Claude: merge requests, tickets, documentation, chat, alerts. Prompts, schemas, a CLI anyone in the company can use, CI workflows for GitHub and GitLab, and the guardrails that make it safe to hand to everyone. |

Each example is self-contained and documented so it can be lifted into another company as a starting point.
